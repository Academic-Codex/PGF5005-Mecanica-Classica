Exercício 2.1 (Teórico)¶

Demonstre que a Hamiltoniana H é uma constante de movimento para quaisquer valores dos parâmetros $\alpha$ e $\beta$. Em seguida, mostre que as funções $F_1 = J_1 + J_2$, para $\beta = 0$, e $F_2 = 3J_1 + 2J_2$, para $\alpha = 0$, também representam constantes de movimento.

a) H como Constante de Movimento¶

A evolução temporal de uma função $F(q, p, t)$ na mecânica Hamiltoniana é dada por: $$ \frac{dF}{dt} = \{F, H\} + \frac{\partial F}{\partial t} $$ onde $\{F, H\}$ é o Parêntese de Poisson. Para a Hamiltoniana $H$ em si, temos: $$ \frac{dH}{dt} = \{H, H\} + \frac{\partial H}{\partial t} $$ A Hamiltoniana de Walker-Ford, $H = H_0 + H_1$, não depende explicitamente do tempo, logo: $$ \frac{\partial H}{\partial t} = 0 $$ O Parêntese de Poisson de qualquer função com ela mesma é sempre nulo: $$ \{H, H\} = \sum_{k=1}^{2} \left( \frac{\partial H}{\partial \phi_k} \frac{\partial H}{\partial J_k} - \frac{\partial H}{\partial J_k} \frac{\partial H}{\partial \phi_k} \right) = 0 $$ Portanto, para quaisquer valores de $\alpha$ e $\beta$: $$ \frac{dH}{dt} = 0 + 0 = 0 $$ Isso demonstra que a energia total, representada pela Hamiltoniana H, é uma constante de movimento.

b) $F_1 = J_1 + J_2$ como Constante de Movimento para $\beta = 0$¶

Quando $\beta=0$, a Hamiltoniana se torna: $$ H|_{\beta=0} = J_1 + J_2 - J_1^2 - 3J_1J_2 + J_2^2 + \alpha J_1J_2 \cos(2\phi_1 - 2\phi_2) $$ A função $F_1 = J_1 + J_2$ não depende explicitamente do tempo, então $\frac{\partial F_1}{\partial t} = 0$. Precisamos calcular o Parêntese de Poisson $\{F_1, H\}$: $$ \{F_1, H\} = \frac{\partial F_1}{\partial \phi_1} \frac{\partial H}{\partial J_1} - \frac{\partial F_1}{\partial J_1} \frac{\partial H}{\partial \phi_1} + \frac{\partial F_1}{\partial \phi_2} \frac{\partial H}{\partial J_2} - \frac{\partial F_1}{\partial J_2} \frac{\partial H}{\partial \phi_2} $$ As derivadas de $F_1$ são $\frac{\partial F_1}{\partial J_1} = 1$, $\frac{\partial F_1}{\partial J_2} = 1$ e $\frac{\partial F_1}{\partial \phi_k} = 0$. Substituindo: $$ \{F_1, H\} = 0 - (1)\frac{\partial H}{\partial \phi_1} + 0 - (1)\frac{\partial H}{\partial \phi_2} = -\left( \frac{\partial H}{\partial \phi_1} + \frac{\partial H}{\partial \phi_2} \right) $$ Calculando as derivadas de H: $$ \frac{\partial H}{\partial \phi_1} = -\alpha J_1 J_2 \sin(2\phi_1 - 2\phi_2) \cdot (2) = -2\alpha J_1 J_2 \sin(2\phi_1 - 2\phi_2) $$ $$ \frac{\partial H}{\partial \phi_2} = -\alpha J_1 J_2 \sin(2\phi_1 - 2\phi_2) \cdot (-2) = 2\alpha J_1 J_2 \sin(2\phi_1 - 2\phi_2) $$ Somando as duas: $$ \frac{\partial H}{\partial \phi_1} + \frac{\partial H}{\partial \phi_2} = -2\alpha J_1 J_2 \sin(2\phi_1 - 2\phi_2) + 2\alpha J_1 J_2 \sin(2\phi_1 - 2\phi_2) = 0 $$ Portanto, $\{F_1, H\} = 0$, o que implica $\frac{dF_1}{dt} = 0$. $F_1$ é uma constante de movimento quando $\beta = 0$.

c) $F_2 = 3J_1 + 2J_2$ como Constante de Movimento para $\alpha = 0$¶

Quando $\alpha=0$, a Hamiltoniana é: $$ H|_{\alpha=0} = J_1 + J_2 - J_1^2 - 3J_1J_2 + J_2^2 + \beta J_1J_2^{3/2} \cos(2\phi_1 - 3\phi_2) $$ Para $F_2 = 3J_1 + 2J_2$, temos $\frac{\partial F_2}{\partial J_1} = 3$, $\frac{\partial F_2}{\partial J_2} = 2$ e $\frac{\partial F_2}{\partial \phi_k} = 0$. O Parêntese de Poisson é: $$ \{F_2, H\} = -\frac{\partial F_2}{\partial J_1} \frac{\partial H}{\partial \phi_1} - \frac{\partial F_2}{\partial J_2} \frac{\partial H}{\partial \phi_2} = -\left( 3\frac{\partial H}{\partial \phi_1} + 2\frac{\partial H}{\partial \phi_2} \right) $$ Calculando as derivadas de H: $$ \frac{\partial H}{\partial \phi_1} = -\beta J_1 J_2^{3/2} \sin(2\phi_1 - 3\phi_2) \cdot (2) = -2\beta J_1 J_2^{3/2} \sin(2\phi_1 - 3\phi_2) $$ $$ \frac{\partial H}{\partial \phi_2} = -\beta J_1 J_2^{3/2} \sin(2\phi_1 - 3\phi_2) \cdot (-3) = 3\beta J_1 J_2^{3/2} \sin(2\phi_1 - 3\phi_2) $$ Substituindo no Parêntese de Poisson: $$ 3\frac{\partial H}{\partial \phi_1} + 2\frac{\partial H}{\partial \phi_2} = 3(-2\beta J_1 J_2^{3/2} \sin(2\phi_1 - 3\phi_2)) + 2(3\beta J_1 J_2^{3/2} \sin(2\phi_1 - 3\phi_2)) $$ $$ = -6\beta J_1 J_2^{3/2} \sin(2\phi_1 - 3\phi_2) + 6\beta J_1 J_2^{3/2} \sin(2\phi_1 - 3\phi_2) = 0 $$ Logo, $\{F_2, H\} = 0$, e $\frac{dF_2}{dt} = 0$. $F_2$ é uma constante de movimento quando $\alpha = 0$.

Conclusão¶

Um sistema Hamiltoniano com N graus de liberdade é dito integrável se possuir N constantes de movimento independentes e em involução. O sistema de Walker-Ford tem N=2 graus de liberdade. Em ambos os casos, $\alpha=0$ ou $\beta=0$, o sistema possui duas constantes de movimento independentes (H e $F_1$, ou H e $F_2$). Isso confirma que o sistema é integrável quando uma das perturbações ressonantes é nula.

Considerando a Hamiltoniana (22a), escreva as equações para $\phi_{k}^{(n+1)}$ e $J_{k}^{(n+1)}$ de acordo com o método de Euler simplético.

As equações de Hamilton para o sistema são: $$ \dot{\phi}_k = \frac{\partial H}{\partial J_k} \quad , \quad \dot{J}_k = -\frac{\partial H}{\partial \phi_k} $$ O método de Euler simplético, conforme as equações (4a) e (4b) do enunciado, com a identificação $q \rightarrow \phi$ e $p \rightarrow J$, é dado por: $$ \phi_{k}^{(n+1)} = \phi_{k}^{(n)} + \Delta t \frac{\partial H}{\partial J_{k}}\bigg|_{(\phi^{(n+1)}, J^{(n)})} \quad \text{(Implícito)} $$ $$ J_{k}^{(n+1)} = J_{k}^{(n)} - \Delta t \frac{\partial H}{\partial \phi_{k}}\bigg|_{(\phi^{(n+1)}, J^{(n)})} \quad \text{(Explícito, após encontrar } \phi^{(n+1)}) $$ Primeiro, calculamos as derivadas parciais da Hamiltoniana completa: $$ H = J_1 + J_2 - J_1^2 - 3J_1J_2 + J_2^2 + \alpha J_1J_2\cos(2\phi_1 - 2\phi_2) + \beta J_1J_2^{\frac{3}{2}}\cos(2\phi_1 - 3\phi_2) $$ Derivadas em relação a $J_k$: $$ \frac{\partial H}{\partial J_1} = 1 - 2J_1 - 3J_2 + \alpha J_2\cos(2\phi_1 - 2\phi_2) + \beta J_2^{\frac{3}{2}}\cos(2\phi_1 - 3\phi_2) $$ $$ \frac{\partial H}{\partial J_2} = 1 - 3J_1 + 2J_2 + \alpha J_1\cos(2\phi_1 - 2\phi_2) + \frac{3}{2}\beta J_1J_2^{\frac{1}{2}}\cos(2\phi_1 - 3\phi_2) $$ Derivadas em relação a $\phi_k$: $$ \frac{\partial H}{\partial \phi_1} = -2\alpha J_1J_2\sin(2\phi_1 - 2\phi_2) - 2\beta J_1J_2^{\frac{3}{2}}\sin(2\phi_1 - 3\phi_2) $$ $$ \frac{\partial H}{\partial \phi_2} = 2\alpha J_1J_2\sin(2\phi_1 - 2\phi_2) + 3\beta J_1J_2^{\frac{3}{2}}\sin(2\phi_1 - 3\phi_2) $$ Agora, substituímos essas derivadas nas equações do método de Euler simplético.

Equações para $\phi_k^{(n+1)}$ (Sistema Implícito): Para $k=1$: $$ \phi_{1}^{(n+1)} = \phi_{1}^{(n)} + \Delta t \left[ 1 - 2J_1^{(n)} - 3J_2^{(n)} + \alpha J_2^{(n)}\cos(2\phi_1^{(n+1)} - 2\phi_2^{(n+1)}) + \beta (J_2^{(n)})^{\frac{3}{2}}\cos(2\phi_1^{(n+1)} - 3\phi_2^{(n+1)}) \right] $$ Para $k=2$: $$ \phi_{2}^{(n+1)} = \phi_{2}^{(n)} + \Delta t \left[ 1 - 3J_1^{(n)} + 2J_2^{(n)} + \alpha J_1^{(n)}\cos(2\phi_1^{(n+1)} - 2\phi_2^{(n+1)}) + \frac{3}{2}\beta J_1^{(n)}(J_2^{(n)})^{\frac{1}{2}}\cos(2\phi_1^{(n+1)} - 3\phi_2^{(n+1)}) \right] $$ Este é um sistema de duas equações não-lineares para as duas incógnitas $\phi_1^{(n+1)}$ e $\phi_2^{(n+1)}$, que precisa ser resolvido numericamente a cada passo de tempo (e.g., pelo método de Newton).

Equações para $J_k^{(n+1)}$ (Sistema Explícito): Uma vez encontrados os valores de $\phi_1^{(n+1)}$ e $\phi_2^{(n+1)}$, podemos calcular diretamente $J_k^{(n+1)}$: Para $k=1$: $$ J_{1}^{(n+1)} = J_{1}^{(n)} - \Delta t \left[ -2\alpha J_1^{(n)}J_2^{(n)}\sin(2\phi_1^{(n+1)} - 2\phi_2^{(n+1)}) - 2\beta J_1^{(n)}(J_2^{(n)})^{\frac{3}{2}}\sin(2\phi_1^{(n+1)} - 3\phi_2^{(n+1)}) \right] $$ Para $k=2$: $$ J_{2}^{(n+1)} = J_{2}^{(n)} - \Delta t \left[ 2\alpha J_1^{(n)}J_2^{(n)}\sin(2\phi_1^{(n+1)} - 2\phi_2^{(n+1)}) + 3\beta J_1^{(n)}(J_2^{(n)})^{\frac{3}{2}}\sin(2\phi_1^{(n+1)} - 3\phi_2^{(n+1)}) \right] $$

from dataclasses import dataclass
import numpy as np

@dataclass(frozen=True)
class WFParams:
    alpha: float
    beta: float

def H(phi1, phi2, J1, J2, p: WFParams):
    H0 = J1 + J2 - J1**2 - 3*J1*J2 + J2**2
    term_a = p.alpha * J1 * J2 * np.cos(2*phi1 - 2*phi2)
    term_b = p.beta  * J1 * J2**1.5 * np.cos(2*phi1 - 3*phi2)
    val = H0 + term_a + term_b
    return np.where((J1<0)|(J2<0), np.inf, val)

def dH_dJ1(phi1,phi2,J1,J2,p):
    return 1 - 2*J1 - 3*J2 + p.alpha*J2*np.cos(2*phi1-2*phi2) + p.beta*J2**1.5*np.cos(2*phi1-3*phi2)

def dH_dJ2(phi1,phi2,J1,J2,p):
    return 1 - 3*J1 + 2*J2 + p.alpha*J1*np.cos(2*phi1-2*phi2) + 1.5*p.beta*J1*J2**0.5*np.cos(2*phi1-3*phi2)

def dH_dphi1(phi1,phi2,J1,J2,p):
    return -2*p.alpha*J1*J2*np.sin(2*phi1-2*phi2) - 2*p.beta*J1*J2**1.5*np.sin(2*phi1-3*phi2)

def dH_dphi2(phi1,phi2,J1,J2,p):
    return  2*p.alpha*J1*J2*np.sin(2*phi1-2*phi2) + 3*p.beta*J1*J2**1.5*np.sin(2*phi1-3*phi2)

# segundas derivadas (para o Jacobiano do Newton)
def d2H_dJ1dphi1(phi1,phi2,J1,J2,p):
    return -2*p.alpha*J2*np.sin(2*phi1-2*phi2) - 2*p.beta*J2**1.5*np.sin(2*phi1-3*phi2)

def d2H_dJ1dphi2(phi1,phi2,J1,J2,p):
    return  2*p.alpha*J2*np.sin(2*phi1-2*phi2) + 3*p.beta*J2**1.5*np.sin(2*phi1-3*phi2)

def d2H_dJ2dphi1(phi1,phi2,J1,J2,p):
    return -2*p.alpha*J1*np.sin(2*phi1-2*phi2) - 3*p.beta*J1*J2**0.5*np.sin(2*phi1-3*phi2)

def d2H_dJ2dphi2(phi1,phi2,J1,J2,p):
    return  2*p.alpha*J1*np.sin(2*phi1-2*phi2) + 4.5*p.beta*J1*J2**0.5*np.sin(2*phi1-3*phi2)

# wf/lu.py
import numpy as np

def lu_decomp_pivot(A):
    A = A.copy().astype(float)
    n = A.shape[0]
    P = np.eye(n); L = np.zeros_like(A); U = A.copy()
    for k in range(n):
        i = np.argmax(np.abs(U[k:,k])) + k
        if i != k:
            U[[k,i]] = U[[i,k]]
            P[[k,i]] = P[[i,k]]
            L[[k,i],:k] = L[[i,k],:k]
        L[k,k] = 1.0
        for j in range(k+1,n):
            L[j,k] = U[j,k]/U[k,k]
            U[j,k:] -= L[j,k]*U[k,k:]
    return P,L,U

def lu_solve(P,L,U,b):
    Pb = P @ b
    # Ly = Pb
    y = np.zeros_like(b, dtype=float)
    for i in range(L.shape[0]):
        y[i] = Pb[i] - L[i,:i] @ y[:i]
    # Ux = y
    x = np.zeros_like(b, dtype=float)
    for i in range(U.shape[0]-1, -1, -1):
        x[i] = (y[i] - U[i,i+1:] @ x[i+1:]) / U[i,i]
    return x

import numpy as np

def newton(g, J, x0, lin_solve, tol=1e-10, max_iter=20):
    x = np.array(x0, dtype=float)
    for _ in range(max_iter):
        r = g(x)
        if np.linalg.norm(r, ord=2) < tol:
            return x
        A = J(x)
        dx = lin_solve(A, -r)
        x = x + dx
    return x  # melhor aproximação

import numpy as np


def step_symplectic_euler(state, dt, params, newton_solve):
    phi = state[:2].copy(); J = state[2:].copy()
    J1,J2 = J

    def g(x):
        φ1,φ2 = x
        return np.array([
            φ1 - phi[0] - dt * dH_dJ1(φ1,φ2,J1,J2,params),
            φ2 - phi[1] - dt * dH_dJ2(φ1,φ2,J1,J2,params),
        ])

    def Jg(x):
        φ1,φ2 = x
        return np.array([
            [1 - dt*d2H_dJ1dphi1(φ1,φ2,J1,J2,params), -dt*d2H_dJ1dphi2(φ1,φ2,J1,J2,params)],
            [-dt*d2H_dJ2dphi1(φ1,φ2,J1,J2,params),      1 - dt*d2H_dJ2dphi2(φ1,φ2,J1,J2,params)]
        ])

    phi_next = newton_solve(g, Jg, phi)   # resolve o passo implícito
    φ1,φ2 = phi_next
    J_next = np.array([
        J1 - dt * dH_dphi1(φ1,φ2,J1,J2,params),
        J2 - dt * dH_dphi2(φ1,φ2,J1,J2,params),
    ])
    return np.concatenate([phi_next, J_next])

# wf/poincare.py
import numpy as np

def unwrap(a): return (a + np.pi)%(2*np.pi) - np.pi

def collect_section(step_fn, state0, dt, steps, phi1_star=0.0, burn=200, p1_from=None):
    s = np.array(state0, float)
    φ1_prev = unwrap(s[0]); star = unwrap(phi1_star)
    pts = []; cross = 0
    for _ in range(steps):
        s_prev = s.copy()
        s = step_fn(s, dt)
        φ1 = unwrap(s[0])
        if (φ1_prev < star <= φ1) and (p1_from is None or p1_from(s) > 0):
            # interp linear
            t = (star - φ1_prev) / (φ1 - φ1_prev + 1e-15)
            s_star = s_prev + t*(s - s_prev)
            cross += 1
            if cross > burn:
                pts.append(s_star.copy())
        φ1_prev = φ1
    return np.array(pts)

def collect_poincare_events(integrator, initial_state, dt, steps,
                            phi1_star, burn):
    """
    Coleta cruzamentos exatos com φ1 = phi1_star e p1>0
    usando interpolação linear entre passos adjacentes.
    """
    s = np.array(initial_state, float)
    pts = []
    crosses = 0

    def unwrap(a):  # mantém a fase contínua em (-π, π]
        return (a + np.pi) % (2*np.pi) - np.pi

    φ1 = unwrap(s[0]); star = unwrap(phi1_star)

    for _ in range(steps):
        s_prev = s.copy()
        φ1_prev = unwrap(s_prev[0])

        s = integrator.symplectic_euler_step(s_prev, dt)
        φ1_now = unwrap(s[0])

        # orientação p1>0 no estado "agora"
        # (se tiver um helper p1_from(J1,φ1), use; aqui, como estamos em (J,φ), p1>0 ↔ sin(φ1)<0)
        p1_pos = (np.sin(φ1_now) < 0)

        # cruzamento de baixo para cima: φ1_prev < star <= φ1_now
        if (φ1_prev < star <= φ1_now) and p1_pos:
            # interpolação linear na fase para estimar o estado "na seção"
            t = (star - φ1_prev) / (φ1_now - φ1_prev + 1e-15)
            s_star = s_prev + t * (s - s_prev)
            crosses += 1
            if crosses > burn:
                pts.append(s_star)

        φ1 = φ1_now

    return np.array(pts)

def collect_poincare_fast(integrator, s0, dt, phi1_star=0.0, burn=50,
                          target_cross=400, max_steps=400_000):
    import numpy as np
    s = np.array(s0, float)

    # 1) se começar exatamente na seção, desce um epsilon
    if ((s[0] - phi1_star) % (2*np.pi)) == 0:
        s[0] = s[0] - 1e-6

    pts = []
    crosses = 0
    unwrap = lambda a: (a + np.pi) % (2*np.pi) - np.pi
    star = unwrap(phi1_star)
    phi1_prev = unwrap(s[0])
    step = integrator.symplectic_euler_step

    for _ in range(max_steps):
        s_prev = s
        s = step(s, dt)
        phi1_now = unwrap(s[0])

        # 2) desigualdade mais robusta para pegar o 1º cruzamento
        crossed = (phi1_prev <= star) and (phi1_now > star)

        if crossed:
            # interpola o estado na seção
            t = (star - phi1_prev) / (phi1_now - phi1_prev + 1e-15)
            s_star = s_prev + t*(s - s_prev)

            # 3) checa orientação com p1>0 a partir do estado interpolado
            phi1_s, phi2_s, J1_s, J2_s = s_star
            p1_s = p_from_Jphi(J1_s, phi1_s)
            if p1_s > 0:
                crosses += 1
                if crosses > burn:
                    pts.append(s_star)
                    if len(pts) >= target_cross:
                        break
        phi1_prev = phi1_now

    return np.array(pts)
